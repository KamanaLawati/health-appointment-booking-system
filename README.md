# Health Appointment Booking System

The Health Appointment Booking System is a web-based healthcare management application developed using **Python, Django, Django REST Framework, and Oracle Database**.

The system is designed to simplify the management of departments, doctors, patients, and medical appointments. It provides a user-friendly web interface for registering patients, booking appointments, viewing appointment records, and updating appointment statuses.

The project also includes CRUD operations, REST API endpoints, Django ORM integration, related and complex database queries, appointment reports, and background task functionality. Oracle Database is used to store and manage the application data.

This project demonstrates the development of a database-driven healthcare application using a layered architecture and modern web development technologies.
